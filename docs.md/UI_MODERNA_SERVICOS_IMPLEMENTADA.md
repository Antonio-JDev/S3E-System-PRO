- **Ícone**: 💰 (roxo)
- **Cor**: Purple-600

**Cálculo Automático**:

```typescript
const stats = useMemo(() => {
  const total = services.length;
  const ativos = services.filter((s) => s.price > 0).length;
  const inativos = total - ativos;
  const precoMedio =
    total > 0 ? services.reduce((sum, s) => sum + s.price, 0) / total : 0;

  return { total, ativos, inativos, precoMedio };
}, [services]);
```
